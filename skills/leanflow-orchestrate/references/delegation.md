# Orchestration delegation

## Assignment packet

When dispatching any worker, provide a self-contained packet, not only a role name or a reference to conversation history:

- **Task, specification, and plan:** objective, stage, constraints, acceptance criteria, and the exact saved specification path with access instructions when present or required. For specification drafting, provide the complete source material or exact accessible source paths/conversation excerpts and state that the specification is not saved yet. Standalone planning/execution may explicitly state that no specification was requested. Provide the exact selected plan path with access instructions, or its complete inline content, when one exists; for research/specification/planning drafts with no plan, explicitly say **no plan exists yet** rather than inventing a path or step IDs. Identify assigned step IDs when available and pending work; include settled decisions and relevant completed-step evidence. Orchestrated planning and execution require access to the exact saved specification, not an inline substitute.
- **Source resolution:** workspace/source root, bases for relative specification, source-material, and plan references, and actual locations or supported discovery routes for the applicable canonical skill bodies. Specification drafters read [`../../leanflow-to-spec/SKILL.md`](../../leanflow-to-spec/SKILL.md); planners read [`../../leanflow-plan/SKILL.md`](../../leanflow-plan/SKILL.md); executors read [`../../leanflow-execute/SKILL.md`](../../leanflow-execute/SKILL.md) and its [delegation reference](../../leanflow-execute/references/delegation.md). Reviewers read the delegated-review section below and [code review](../../leanflow-code-review/SKILL.md), not the top-level orchestration workflow. Include exact sources for conditionally selected supporting companions. Workers must load the actual applicable bodies and delegation reference, not treat a skill name or link as loaded instructions. Relative links resolve from the file containing them, not the worker's assumed working directory. Missing access to required content blocks that dependent work.
- **Ownership and dependencies:** exact writable paths/areas, read-only context, exclusions, shared interfaces, prerequisites, and integration owner. Identify the coordinator as sole specification/shared-plan writer; drafting workers return content without saving either artifact. Do not assign overlapping writes.
- **Permissions and checks:** read/write/execution limits, destructive/external-effect consent, explicit delegation-only constraints, allowed assigned checks with expected observations, coordinator-reserved gates, and actions requiring a blocker or `REPLAN_REQUIRED`. Role declarations do not widen authority.
- **Return evidence:** assigned stage and step IDs when available, source citations or changed paths, results, exact checks/observations, unrun checks and reasons, blockers, and partial effects. Require actual results, not a launch receipt. Workers must not invoke other workers or orchestration workflows.

## Delegated review

When independent source review is requested or justified by concrete risk and permitted delegation is selected, provide the supplied changes or exact source boundary, inspected revision when available, plan/acceptance criteria, relevant evidence, and independence requirements through the assignment packet above. Keep reviewer ownership separate from implementation; a self-review is not independent review. The reviewer loads this reference and [code review](../../leanflow-code-review/SKILL.md), which owns substantive inspection, evidence standards, findings, and correction-review methodology. This assignment remains source-only: no edits, command execution, payload execution, or delegation; a companion cannot widen those limits. Return findings and scope/limitations through the permitted channel without writing the specification or shared plan. Supplied check evidence is not a check the reviewer ran. Loading this contract does not itself request a reviewer, start orchestration, or add an independent-review gate.
